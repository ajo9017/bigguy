# 네이버 블로그 후기 자동 작성

사진과 영상만 받아도 맥락(가게, 메뉴, 분위기, 안내문)을 읽어 바로 올릴 수 있는 네이버 블로그 글을 쓴다. 확인 질문은 꼭 필요할 때만 한다.

## 1. 사진에서 정보 뽑기
- 사진을 순서대로 보며 다음을 적는다: 간판 상호와 문구(since 등), 입간판·안내문 글자(영업시간, 웨이팅 방식, 포장 여부, 화장실, 주의사항), 실내 분위기(사인, 인테리어), 기본 반찬, 메뉴별 구성(재료, 담음새, 양), 먹는 법 안내문.
- 영상은 프레임을 뽑아 같은 방식으로 본다(`ffmpeg -i in.mp4 -vf fps=1/3 frame_%02d.jpg`). 소리가 있으면 분위기 묘사에만 쓴다.
- 사진에 없는 맛 평가는 지어내지 않는다. 겉으로 보이는 것(윤기, 색, 양, 식감 단서)으로 묘사하고, 맛 표현이 필요한 자리는 `[맛 한 줄: 직접 채우기]`로 남긴다.

## 2. 상호 검색으로 자료 모으기
- `상호 + 동네 + 맛집/후기`로 웹 검색한다. 네이버 블로그 검색에서 인기순(조회수가 높은 글이 위로 오는 순) 상위 글을 먼저 읽는다. 네이버가 막히면 다이닝코드, 식신, 망고플레이트, 기사 순으로 본다.
- 확인할 것: 주소, 영업시간·브레이크타임, 휴무, 메뉴와 가격, 웨이팅 방식, 주차, 방송 출연, 대표 메뉴. 출처끼리 다르면 사진 속 안내문을 우선하고, 그래도 다르면 "방문 전 확인"을 붙인다.
- 상위 글에서 공통으로 쓰는 키워드(동네 맛집, 대표 메뉴, 웨이팅)와 구성 순서를 따라간다. 문장을 베끼지 않는다.

## 3. 글 구조 (상위 노출 글의 공통 형식)
1. **제목**: `동네 맛집 상호 | 대표메뉴1 대표메뉴2 + 핵심 포인트(웨이팅/후기)`. 30~40자, 핵심 키워드를 앞에.
2. **도입 2~3줄**: 왜 갔는지, 한 줄 결론.
3. **기본 정보 박스**: 📍주소 / ⏰영업시간 / 💤휴무 / 🚗주차 / 📝웨이팅 / 🥡포장.
4. **외관·웨이팅**: 간판, 입간판 안내문 요약.
5. **내부·분위기**: 사인, 좌석, 기본 세팅.
6. **메뉴별 후기**: 메뉴마다 소제목 + 사진 + 3~6줄. 가격 표기.
7. **꿀팁**: 안내문에 적힌 먹는 법, 방문 시간 팁.
8. **총평**: 재방문 의사, 추천 대상, 별점(선택).
9. **해시태그** 10~20개.

## 4. 문체
- 1인칭 구어체 존댓말("~했어요", "~더라고요"). 한 문단 1~3줄, 줄바꿈 자주.
- 이모지는 소제목과 정보 박스에만 적당히.
- 사진 자리에는 `[사진N: 무엇]`을 넣어 업로드 순서를 알려준다. 사용자 사진 번호와 맞춘다.
- 사진 속 다른 손님 얼굴, 남의 개인 정보는 쓰지 않는다. 벽 사인의 유명인 이름은 확실히 읽히는 것만, 단정하지 않고 쓴다.
- 협찬이 아니면 "내돈내산"을 붙인다(사용자가 다르게 말하면 따른다).

## 5. 결과물
- `blog/YYYY-MM-DD-상호.md`(작업 폴더 또는 scratchpad)에 저장하고 사용자에게 파일로 보낸다. 네이버 에디터에 그대로 붙여 넣을 수 있게 마크다운 기호는 소제목 정도만 쓴다.
- 끝에 "확인 필요" 목록(가격·시간처럼 출처가 갈린 정보, 직접 채울 맛 한 줄)을 따로 적는다.
- 자동 발행은 하지 않는다(네이버 블로그 글쓰기 API가 없다). 사용자가 붙여 넣고 사진만 올리면 되게 만든다.
